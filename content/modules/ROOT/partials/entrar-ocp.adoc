// Linha de entrada do console do OpenShift e dos Traces --
// tudo que passa pelo OAuth do cluster. Incluida na PRIMEIRA indicacao de cada
// uma dessas telas, em cada pagina.
//
// POR QUE UM ATRIBUTO PROPRIO, e nao o 'senha_persona': sao perguntas
// diferentes, e confundi-las produz uma linha errada. A persona do Keycloak
// entra no GitLab e no Developer Hub, mas no OpenShift ela nao tem papel
// nenhum -- o login ACONTECE e a tela nasce vazia, e quem le conclui que a
// senha esta errada. Nos dois ambientes que existem hoje a credencial do
// console vem de FORA do cluster (a pagina do pedido no RHDP), entao o
// atributo nasce vazio e esta linha vira um ponteiro honesto.
ifeval::["{senha_console}" != ""]
ifeval::["{usuario_console_dev}" == ""]
[NOTE.credencial]
====
**Para entrar:** usuário `{usuario_console}` · senha `{senha_console}`
====
endif::[]
ifeval::["{usuario_console_dev}" != ""]
[NOTE.credencial]
====
**Para entrar:** perfil Infra -- usuário `{usuario_console}` · senha `{senha_console}` +
perfil Dev -- usuário `{usuario_console_dev}` · senha `{senha_console_dev}` +
ifeval::["{usuario_console_plataforma}" != ""]
Plataforma, só leitura e o mesmo para a turma -- usuário `{usuario_console_plataforma}` · senha `{senha_console_plataforma}` +
endif::[]
Para trocar de perfil: **Log out** e entre com o outro.
====
endif::[]
endif::[]
ifeval::["{senha_console}" == ""]
[NOTE.credencial]
====
**Para entrar:** o usuário e a senha do OpenShift são os da página do seu
pedido no RHDP -- os mesmos que o e-mail de criação do ambiente trouxe. O
terminal à direita já está autenticado e não pede nada.
====
endif::[]
