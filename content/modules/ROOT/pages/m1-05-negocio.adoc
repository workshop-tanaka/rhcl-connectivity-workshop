[WARNING.antes]
====
**Antes: a parte 1.2 (ou o aquecimento) nos últimos 15 min.** Esta parte só lê.
Sem tráfego com chave, o painel sai vazio e nada avisa -- por isso o script
consulta o Thanos ao começar e diz quantas chamadas há na janela. Se for zero,
ele **pergunta** se roda a parte 1.2 agora e volta.
====

Até aqui foi código de status. Agora é a pergunta que a área comercial faz.

== Terminal

[source,bash,role="execute"]
----
bash scripts/demo.sh ato4
----

O que tem de aparecer: as séries quebradas por `plan` e a cota diária
restante de cada plano. Depois, a mesma consulta direto no Thanos:
`sum by (plan) (authorized_calls)`.

== Navegador

{grafana_url}/d/rhcl-negocio-planos[Planos comerciais^] -- o dashboard desta parte. Os
quatro primeiros painéis são a rajada; o quinto é a cota diária consumida por
plano. Confira o seletor de datasource no topo: **Thanos**.

Os dashboards de fábrica do RHCL agregam **sem** quebrar por plano: são
anteriores ao TelemetryPolicy. Se você abrir um deles procurando os tiers, não
vai achar -- e o motivo é esse, não um defeito de coleta.

== Evidência

Aqui a tela **é** a evidência. Para o consumo por parceiro, onde o tráfego de
teste aparece isolado: {grafana_url}/d/rhcl-negocio-parceiros[Consumo por parceiro^].

== Configuração

{config_url}/base/policies-telemetry/prod-web-telemetry.yaml[prod-web-telemetry.yaml^]
-- a policy que injeta o label `plan` na métrica. Sem ela a série responde "quantos 429 houve"; com
ela responde "o tier free está saturando", que é outra conversa.

== O que isso prova

A cadeia que você percorreu -- PlanPolicy → TelemetryPolicy → Limitador →
Prometheus → Thanos → Grafana -- já existia no cluster. O que a camada de demo
acrescentou foi **uma dimensão**: o label `plan`. É a diferença entre saber
quantos 429 houve e saber que o tier free está saturando.

== Fim da primeira metade do Módulo 1

A API deste ambiente está fechada por padrão, atende três planos comerciais
diferentes no mesmo endereço, e o consumo de cada cliente aparece em painel --
e nada disso passou por uma linha de código da aplicação.
