= Fase 3 — A primeira API: o que há nesta fase
:navtitle: O que há nesta fase

**Leitura · ~1 min · não muda estado**

projeto continuar inteira. O que há nela: Publicar uma API do zero e levá-la de aberta a governada: a rota, a chave, o plano, o nome por `DNSPolicy`, e a escolha entre chave e identidade.
